## دور Struts 2 في تطبيق الويب

يعمل Struts 2 **حصريًا داخل طبقة الويب** في بنية متعددة الطبقات نموذجية.

### البنية العامة

يمكن هيكلة تطبيق ويب نموذجي على النحو التالي:

### 1️⃣ مستوى الويب

* واجهة المستخدم (المتصفح)
* إدارة طلبات HTTP
* إنشاء الاستجابات
* **يوجد Struts 2 حصريًا في هذا المستوى**

### 2️⃣ مستوى الأعمال

* ينفذ قواعد الأعمال
* مثال: حساب الراتب، إنشاء فاتورة
* يستخدم:
  * بيانات من مستوى الويب
  * بيانات من قاعدة البيانات عبر مستوى DAO

### 3️⃣ مستوى DAO / JPA / JDBC

* إدارة الوصول إلى البيانات
* DAO: كائنات الوصول إلى البيانات (Data Access Objects)
* JPA: واجهة برمجة تطبيقات الاستمرارية في Java (Java Persistence API)
* JDBC: الوصول إلى قاعدة البيانات على مستوى منخفض
* تعمل JPA كـ ORM (مخطط علاقات الكائنات)

### 4️⃣ تكامل المستويات

يمكن توفيره بواسطة:

* **Spring**
* **EJB3 (Enterprise Java Bean)**

## تنظيم الأمثلة

تستخدم معظم الأمثلة في هذا المستند **مستوى الويب فقط** للتركيز على Struts 2.

في نهاية المستند، يتم إنشاء **تطبيق ويب متعدد الطبقات كامل**:
* مستوى الويب
* مستوى الأعمال
* مستوى DAO
* مستوى JPA / Hibernate
* الوصول إلى قاعدة البيانات عبر JDBC
يتم توفير مستويات الأعمال والاستمرارية كأرشيفات JAR حتى يتمكن القارئ من التركيز بشكل أساسي على مستوى الويب.
